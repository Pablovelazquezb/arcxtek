# arcxtek

Sitio web corporativo de **Arcxtek** - Ingeniería y desarrollo de software a la medida de alto rendimiento.

## Características
- Diseño moderno, minimalista y responsivo.
- Carrusel infinito acelerado por GPU con logotipos de clientes.
- Estructura limpia y semántica (Vanilla HTML5, Vanilla CSS, Vanilla JavaScript).
- Cero dependencias externas en tiempo de ejecución.
- Optimizado para despliegue en Vercel.

## Desarrollo Local
```bash
python3 -m http.server 4321
```
Abre `http://localhost:4321` en tu navegador.
